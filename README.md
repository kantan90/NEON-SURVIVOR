# NEON SURVIVOR

**ネオンの闇を、生きのびろ。**

[LÖVE](https://love2d.org/)（Lua）で作った、ネオン風の見下ろし型サバイバルシューティングです。
押し寄せる敵を撃ち倒して経験値を集め、レベルアップのたびに能力を選んで強くなりながら、できるだけ長く生きのびます。

![タイトル画面](screenshots/title.png)

![プレイ画面](screenshots/late.png)

## 特徴

- **23種類の能力**：レベルアップのたびに3枚のカードから1つ選びます。組み合わせでプレイが毎回変わります
- **4種類の敵とボス**：突進してくる敵、弾を撃つ敵、倒すと分裂する敵などが出てきます。90秒ごとにボスが現れます
- **包囲網イベント**：40秒ごとに、周りをぐるっと敵に囲まれます
- **ネオンの光の演出**：加算合成のグロー、パーティクル、衝撃波、ヒットストップで手応えを出しています
- **音声ファイルなし**：効果音はすべてプログラムで波形を作って鳴らしています
- **ベスト記録の保存**と、**画面の揺れの強さ切り替え**（強 / 弱 / なし）

## 遊び方

### exe 版（Windows）

[Releases](../../releases) から `NEON_SURVIVOR.zip` をダウンロードして展開し、`NEON_SURVIVOR.exe` を起動します。
LÖVE をインストールしなくても遊べます。

### ソースから起動

1. [LÖVE 11.5](https://love2d.org/) をインストールします
2. このフォルダを `love.exe` にドラッグ＆ドロップします
   （Windows で `C:\Program Files\LOVE` にインストールしてある場合は、`play.bat` をダブルクリックするだけで起動します）

## 操作方法

| キー | 動作 |
|---|---|
| WASD / 矢印キー | 移動 |
| マウス | 狙う（オート射撃） |
| 左クリック | 撃つ（オート射撃が OFF のとき） |
| スペース / Shift / 右クリック | ダッシュ（一瞬だけ無敵） |
| F | オート射撃 ON / OFF |
| V | 画面の揺れ 強 / 弱 / なし |
| P / Esc | ポーズ |
| F11 | フルスクリーン |

## exe のビルド（Windows）

`build_exe.bat` をダブルクリックすると、`../dist/NEON_SURVIVOR/` に exe と、配布用の `NEON_SURVIVOR.zip` が作られます。
LÖVE が `C:\Program Files\LOVE` にインストールされている必要があります。

## 動作チェック（自動プレイ）

```
love . --test
```

無敵状態で5分半を自動プレイしてから終了します。結果はセーブフォルダ（Windows では `%APPDATA%\LOVE\neon_survivor\`）に保存されます。

- `test_log.txt`：撃破数、レベル、処理の重さなど
- `test_*.png`：各画面のスクリーンショット
- `test_error.txt`：エラーが起きたときの内容
